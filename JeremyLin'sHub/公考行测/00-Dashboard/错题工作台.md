# 错题工作台

<div class="xc-hero xc-hero-errors">
  <div>
    <span class="xc-kicker">Workbench</span>
    <strong>错题流转工作台</strong>
  </div>
  <span>未复盘、待复练、已掌握</span>
</div>

> [!quote] 使用方式
> 这里不看总量焦虑，只处理错题流转：未复盘、待复练、高优先级、已掌握。

## 未复盘错题

```dataview
TABLE
  date AS "日期",
  module AS "模块",
  question_type AS "题型",
  wrong_reason AS "错因",
  review_priority AS "优先级"
FROM "公考行测/01-错题库"
WHERE type = "行测错题"
  AND status = "未复盘"
SORT date DESC
LIMIT 20
```

---

## 待复练错题

```dataview
TABLE
  module AS "模块",
  question_type AS "题型",
  wrong_reason AS "错因",
  review_priority AS "优先级",
  next_review AS "下次复练",
  status AS "状态"
FROM "公考行测/01-错题库"
WHERE type = "行测错题"
  AND status != "已掌握"
SORT review_priority ASC, next_review ASC
LIMIT 25
```

---

## 按错因分类

```dataview
TABLE
  length(rows) AS "错题数"
FROM "公考行测/01-错题库"
WHERE type = "行测错题"
  AND status != "已掌握"
GROUP BY wrong_reason AS "错因"
SORT length(rows) DESC
```

---

## 按模块分类

```dataview
TABLE
  length(rows) AS "错题数"
FROM "公考行测/01-错题库"
WHERE type = "行测错题"
  AND status != "已掌握"
GROUP BY module AS "模块"
SORT length(rows) DESC
```

## 最近 7 天新增

```dataview
TABLE
  date AS "日期",
  module AS "模块",
  question_type AS "题型",
  wrong_reason AS "错因",
  review_priority AS "优先级",
  status AS "状态"
FROM "公考行测/01-错题库"
WHERE type = "行测错题"
  AND date >= date(today) - dur(7 days)
SORT date DESC
LIMIT 20
```
