## 二、今日新增错题

```dataview
TABLE 
  module AS "模块",
  question_type AS "题型",
  wrong_reason AS "错因",
  review_priority AS "优先级",
  status AS "状态"
FROM "01-错题库"
WHERE type = "行测错题"
  AND date = date(today)
SORT review_priority ASC
```

## 三、今日待复练完成情况

```dataview
TABLE 
  module AS "模块",
  question_type AS "题型",
  wrong_reason AS "错因",
  next_review AS "原定复练日",
  status AS "状态"
FROM "01-错题库"
WHERE type = "行测错题"
  AND next_review <= date(today)
  AND status != "已掌握"
SORT review_priority ASC, next_review ASC
```
