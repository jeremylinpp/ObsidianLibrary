# 🧠 公考行测复盘总看板

> [!quote] 今日原则
> 不收藏错题，只沉淀方法。  
> 每一道错题都要回答三个问题：我为什么错？这类题怎么做？下次如何避免？

---

## 🚨 今日待复练

```dataview
TABLE 
  module AS "模块",
  question_type AS "题型",
  wrong_reason AS "错因",
  review_priority AS "优先级",
  next_review AS "下次复练",
  status AS "状态"
FROM "01-错题库"
WHERE type = "行测错题"
  AND status != "已掌握"
  AND next_review <= date(today)
SORT review_priority ASC, next_review ASC
```

---

## 🔥 P0 高频错题

```dataview
TABLE 
  date AS "日期",
  module AS "模块",
  question_type AS "题型",
  wrong_reason AS "错因",
  time_spent AS "用时/秒",
  status AS "状态"
FROM "01-错题库"
WHERE type = "行测错题"
  AND review_priority = "P0"
SORT date DESC
LIMIT 15
```
