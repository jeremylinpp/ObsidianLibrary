## 今日待复练

```dataview
TABLE
  module AS "模块",
  question_type AS "题型",
  wrong_reason AS "错因",
  review_priority AS "优先级",
  next_review AS "下次复练",
  status AS "状态"
FROM "公考行测/01-错题库"
WHERE type = "行测错题"
  AND status != "已掌握"
  AND next_review <= date(today)
SORT review_priority ASC, next_review ASC
LIMIT 10
```

## P0 高频错题

```dataview
TABLE
  date AS "日期",
  module AS "模块",
  question_type AS "题型",
  wrong_reason AS "错因",
  status AS "状态"
FROM "公考行测/01-错题库"
WHERE type = "行测错题"
  AND review_priority = "P0"
  AND status != "已掌握"
SORT date DESC
LIMIT 10
```

## 各模块未掌握

```dataview
TABLE
  length(rows) AS "未掌握错题数"
FROM "公考行测/01-错题库"
WHERE type = "行测错题"
  AND status != "已掌握"
GROUP BY module AS "模块"
SORT length(rows) DESC
```
