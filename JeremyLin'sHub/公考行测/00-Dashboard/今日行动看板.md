> [!quote] 今天只做三件事
> 先清到期复练，再处理高优先级错题，最后把新错题变成规则。

## 1. 到期复练

```dataview
TABLE
  module AS "模块",
  question_type AS "题型",
  wrong_reason AS "错因",
  review_priority AS "优先级",
  next_review AS "下次复练",
  status AS "状态"
FROM "公考行测/01-错题库"
WHERE type = "行测错题"
  AND status != "已掌握"
  AND next_review <= date(today)
SORT review_priority ASC, next_review ASC
LIMIT 15
```

---

## 2. 今日新增错题

```dataview
TABLE
  module AS "模块",
  question_type AS "题型",
  wrong_reason AS "错因",
  review_priority AS "优先级",
  status AS "状态"
FROM "公考行测/01-错题库"
WHERE type = "行测错题"
  AND date = date(today)
SORT review_priority ASC
```

---

## 3. 今日优先处理

```dataview
TABLE
  date AS "日期",
  module AS "模块",
  question_type AS "题型",
  wrong_reason AS "错因",
  next_review AS "下次复练"
FROM "公考行测/01-错题库"
WHERE type = "行测错题"
  AND status != "已掌握"
  AND review_priority = "P0"
SORT next_review ASC, date DESC
LIMIT 8
```
